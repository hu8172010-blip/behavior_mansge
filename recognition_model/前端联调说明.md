# 异常行为识别后端交接说明

## 1. 这个压缩包包含什么

- `anomaly_tracker/`：视频上传、人员检测与跟踪、异常行为推理、轨迹绘制和 API。
- `anomaly_training/`：推理时需要的模型结构、类别映射和数据预处理代码。
- `training_runs/protected-v4-seed137/best.pth`：正常、暴力、跌倒三分类模型。
- `yolo26n-pose.pt`：人员检测与跟踪模型。
- `requirements.txt`：后端 Python 依赖。
- `scripts/setup_cuda.ps1`：安装项目使用的 CUDA 版 PyTorch。
- `scripts/verify_cuda.py`：验证 GPU 是否可被 PyTorch 使用。
- `启动异常行为API.ps1`：设置模型路径并启动 API。

压缩包不包含训练视频、数据集和历史训练产物。

## 2. 环境安装

建议使用 Windows、Python 3.11/3.12 和 NVIDIA GPU。

在 PowerShell 中进入解压后的目录：

```powershell
python -m pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File .\scripts\setup_cuda.ps1
python .\scripts\verify_cuda.py
```

如果目标电脑没有兼容的 NVIDIA GPU，需要自行安装适合该电脑的 PyTorch 版本，处理速度也会明显降低。

## 3. 启动 API

```powershell
powershell -ExecutionPolicy Bypass -File .\启动异常行为API.ps1
```

本机访问地址：

```text
http://127.0.0.1:8000
```

同一局域网内其他电脑访问：

```text
http://后端电脑的IPv4地址:8000
```

如果局域网无法访问，需要使用管理员 PowerShell允许 TCP 8000 端口，并确认网络类型为“专用网络”。

## 4. API 调用顺序

```text
POST /api/jobs
GET  /api/jobs/{job_id}
GET  /api/jobs/{job_id}/result
GET  /api/jobs/{job_id}/video
DELETE /api/jobs/{job_id}
```

上传视频：

```javascript
const form = new FormData();
form.append("video", file);

const response = await fetch(`${API_BASE}/api/jobs`, {
  method: "POST",
  body: form,
});

const { job_id } = await response.json();
```

前端随后轮询 `GET /api/jobs/{job_id}`。状态为 `completed` 后，读取结果 JSON 并下载标注视频。

## 5. 跨域和开发代理

当前后端适合前后端同源部署。如果前端开发服务器运行在 `localhost:5173`、`localhost:3000` 等不同端口，浏览器可能触发跨域限制。

推荐前端在开发环境配置代理：

```javascript
// Vite 示例
export default {
  server: {
    proxy: {
      "/api": {
        target: "http://后端电脑IPv4地址:8000",
        changeOrigin: true,
      },
    },
  },
};
```

配置代理后，前端请求使用相对地址 `/api/jobs`，不要把模型权重放进前端 `public` 目录。

## 6. 能力边界

- 当前只支持单视频内的人员轨迹，不支持跨视频确认同一个人的身份。
- 输出是异常行为候选和辅助研判结果，不能代替人工审核或法律判断。
- 模型的跨来源泛化能力有限，换摄像头、场景或拍摄角度后需要重新测试。
