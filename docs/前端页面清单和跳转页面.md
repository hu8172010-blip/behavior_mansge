## 二、页面跳转关系
> 区分两种交互：**路由页面跳转（切换页面）**、**弹窗唤起（当前页面浮层，不切换路由）**

### 全局基础链路
1. `/login` 登录校验成功 → 跳转 `/dashboard`；校验失败停留在登录页
2. `/login` 点击“注册账号” → 进入注册模式；可填写姓名、用户名、密码、确认密码并选择用户类型
3. 注册信息校验成功 → 返回登录模式并自动填充注册账号；注册信息不完整、密码不一致或用户名重复时停留在注册模式并提示错误
4. 任意页面权限校验不通过 → 统一跳转 `/403`

### 1. 总览看板首页 `/dashboard` 向外跳转
1. 点击告警图表条目 → **路由跳转 `/alarm/todo`**（自动携带告警筛选条件）
2. 点击热力高亮区域 → **路由跳转 `/track/history`**（自动带入区域筛选条件）
3. 点击故障/离线设备条目 → **路由跳转 `/device/list`**（自动筛选故障设备）
4. 看板内筛选、刷新操作：仅刷新当前页面数据，无页面跳转

### 2. 轨迹管理模块链路
1. 侧边菜单 / 看板跳转：可进入 `/track/realtime`、`/track/history`
2. `/track/realtime`（实时轨迹管理）
    - 实时轨迹产生告警 → 唤起【告警明细弹窗】
    - 支持Tab切换至事后轨迹（同页面内Tab切换，不切换路由）
3. `/track/history`（事后轨迹查询）
    - 设置条件检索轨迹，支持唤起轨迹回放弹窗
    - 报表导出属于功能操作，无页面跳转

### 3. 设备管理模块链路
1. 总览看板、侧边菜单 → 跳转 `/device/list`
2. `/device/list`（设备列表）
    - 新增设备：当前页面表单操作
    - 选中设备【查看详情/远程控制】→ 唤起【设备详情弹窗】
    - 故障告警触发 → 弹窗创建故障记录
    - 操作完成后刷新列表，不跳转新页面

### 4. 数据管理模块链路【更新日志跳转逻辑】
1. 侧边菜单进入 `/data/index`
2. `/data/index` 功能分流：
    - 选择异常行为记录 → 路由跳转 `/data/abnormal-record`
    - 选择轨迹记录 → 路由跳转 `/data/track-record`
    - 选择数据备份恢复 → 路由跳转 `/data/backup`
    - 选择用户资料管理 → 路由跳转 `/data/user-profile`
    - **选择系统操作日志 → 路由跳转 `/data/operation-log`【新增】**
3. `/data/abnormal-record`：查看事件详情，可唤起【告警明细弹窗】
4. `/data/track-record`：支持唤起轨迹回放弹窗（复用轨迹回放组件）
5. **`/data/operation-log`【新增】**
    - 支持多条件筛选日志记录；点击日志条目弹窗展示完整操作详情
    - 支持日志批量导出，无向外页面跳转；仅作为查询浏览页面

### 5. 告警与工单闭环链路
1. `/track/realtime` 实时告警、看板告警入口 → 跳转 `/alarm/todo`
2. `/alarm/todo`（告警待办队列）
    - 选中告警 → 唤起【告警明细弹窗】，查看告警编号、事件、位置和时间
    - 当前原型支持“确认告警并关闭”，确认后更新告警状态
    - 判定真实告警 → **预留路由 `/workorder/detail/:orderId`**，后续接入自动创建工单
    - 判定误报：弹窗提交样本回流，无页面跳转
3. `/workorder/detail/:orderId`：已配置路由入口，工单处置、归档及返回待办功能待接入

### 6. 用户权限管理模块链路
1. 侧边菜单进入 `/system/index`
2. `/system/index` 功能分流：
    - 进入角色管理 → 路由跳转 `/system/role`
    - 进入账号管理 → 路由跳转 `/system/user`
3. `/system/user`：账号编辑、权限分配、重置密码，点击“自定义权限”唤起权限配置弹窗
    - 弹窗展示当前用户姓名、账号和角色
    - 权限按“总览看板、轨迹管理、告警与工单、数据与审计”分组展示
    - 支持勾选/取消具体权限、调整用户角色，点击“保存权限配置”提交；取消或点击遮罩关闭弹窗

## 四、前端开发规范建议
1. **一级菜单路由清单**
`/dashboard`、`/track/realtime`、`/track/history`、`/device/list`、`/data/index`、`/alarm/todo`、`/system/index`
2. **详情类优先弹窗**：告警详情、设备详情、日志详情优先使用弹窗，减少路由层级；复杂工单使用独立页面路由
3. **参数透传规范**：看板跳转轨迹、设备页面时，自动携带筛选参数（区域ID、设备ID、时间区间），减少用户重复输入
4. **业务闭环回流**：工单处置完成、告警核验完成后，提供快捷入口返回告警待办工作台
5. **操作日志权限控制**：`/data/operation-log` 需要独立权限项，仅授权账号可访问；日志数据仅支持查询，禁止修改、删除
